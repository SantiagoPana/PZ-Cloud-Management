KNOX NET — PZ Cloud Management
PAQUETE PARA WORKSHOP

El ZIP contiene una carpeta KnoxNet-Workshop preparada para el uploader
del juego. No incluye el ejecutable de Windows ni datos personales.

PROBAR ANTES DE PUBLICAR
1. Cerrá Zomboid.
2. Si ya instalaste el mod desde la app, reemplazá esa carpeta completa con
   Contents/mods/PZCloudManagement de este paquete dentro de Zomboid/mods/.
   No mantengas dos copias del mod con el mismo ID activas.
3. Abrí la app Knox Net 2.3.5 (o PZ Cloud 2.3.1), iniciá sesión con Google y dejala abierta.
4. Abrí Zomboid B42.22.1, activá el mod y reiniciá el juego.
5. Comprobá el botón Knox Net centrado arriba con margen y los textos en español;
   probá F8, Actualizar, seleccionar y Descargar copia.
   Verificá también el caso sin app abierta y el botón Descargar aplicación.
6. Cerrá el juego completamente. En la app, recuperá una copia con otro nombre
   y comprobá que el mundo cargue correctamente con la misma build y mods.

PUBLICAR
1. Copiá KnoxNet-Workshop en %UserProfile%/Zomboid/Workshop/.
   Si usás -cachedir, utilizá tu carpeta real de Zomboid.
2. Menú principal → Workshop → Crear y actualizar artículos.
3. Elegí KnoxNet-Workshop, revisá título, descripción e imagen.
4. Conservá el aviso de que necesita la app externa. Elegí la visibilidad y subilo.
5. Steam completará el ID del artículo. Para futuras actualizaciones conservá
   ese ID; no lo reemplaces por el de otro mod.

La prueba automatizada usa Lua y una interfaz simulada. No sustituye la prueba
visual en el juego ni la conexión real de Google. Este paquete todavía NO está publicado en Steam Workshop: el primer upload
requiere tu cuenta de Steam; al subirlo Steam agregará el ID al workshop.txt.

APP DE ESCRITORIO
https://github.com/SantiagoPana/PZ-Cloud-Management/releases/tag/v2.3.5

El mod 2.3.5 es compatible con Knox Net 2.3.5 y PZ Cloud 2.3.1 por el mismo protocolo local.
En el menú Mods aparece como Knox Net; ID: KNManagement; autor: 47.
La app anterior PZ Cloud 2.3.1 incluye el mod anterior; para probar este cambio instalá la carpeta
de este paquete. No vuelvas a usar Instalar botón desde la app vieja después
de instalar esta versión, porque sobreescribiría los archivos actualizados.
