# Knox Net 2.3.4

**PZ Cloud Management**

Tus partidas, a salvo. Abrí **KnoxNet.exe**, iniciá sesión con Google y autorizá el acceso a tus respaldos. Java viene incluido.

1. Cerrá Zomboid y elegí una partida en **Mis partidas**.
2. Pulsá **Guardar partida**. La copia local se verifica y se envía al destino elegido.
3. Para traer una copia, usá **Recuperar partida → En mi carpeta / nube**.
4. En otra PC, abrí esta misma edición e iniciá sesión con la misma cuenta.

Usá **Minimizar a la bandeja** para mantener Knox Net en segundo plano y volver desde el icono junto al reloj. **Salir** desde la bandeja cierra la aplicación.

Podés activar **Guardar automáticamente al cerrar Zomboid**. El respaldo automático espera a que el juego se cierre completamente. **Enviar pendientes** permite reintentar los envíos cuando vuelve la conexión.

En **Configuración** también podés elegir copias solo en esta PC o una carpeta que ya sincronice tu aplicación de nube. Una entrega a carpeta depende de esa aplicación para llegar a Internet.

Para recuperar un mundo usá una versión de Zomboid y mods compatibles. La app conserva una copia del progreso anterior cuando elegís reemplazar una partida.
